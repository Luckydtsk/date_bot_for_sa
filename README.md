# Бот для поиска пары на бал

Telegram-бот для студенческого бала: анкета, лента, взаимный лайк и кнопка «Написать».

Парни видят девушек, девушки — парней. Анкету можно открыть снова и поменять ❤️ или 👎. Пара при этом снимается.

## Как устроено для участника

После `/start` новый человек получает шпаргалку: какая кнопка за что отвечает и как выйти из шага. Потом короткая анкета. На каждом шаге есть «← Назад» и «Отмена».

Когда анкета сохранена, внизу постоянное меню:

- **👀 Анкеты** — все подходящие, по кругу. Фильтры: все, новые, мои ❤️, мои 👎.
- **💘 Кому я нравлюсь** — кто лайкнул и ещё ждёт ответ.
- **💞 Мои пары** — взаимные лайки и «Написать».
- **📝 Моя анкета** — поправить, скрыть или удалить.
- **❓ Помощь** — та же шпаргалка. Команды: `/help`, `/cancel`, `/start`.

`/cancel` и «Отмена» бросают текущий шаг и возвращают в меню. Уже сохранённая анкета остаётся.

## Запуск на компьютере

Нужны Python 3.11+ и токен от [@BotFather](https://t.me/BotFather). Свой Telegram id — у [@userinfobot](https://t.me/userinfobot).

Если папку проекта переносили, старое виртуальное окружение лучше удалить: внутри остались старые пути.

```bash
rm -rf .venv
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env   # если .env ещё нет
```

В `.env`:

```env
BOT_TOKEN=токен_от_BotFather
ADMIN_IDS=твой_telegram_id
DATABASE_URL=sqlite+aiosqlite:///./ball_bot.db
```

```bash
python -m bot.main
```

В логе будет `База на месте` и `Бот запущен`. Остановка — `Ctrl+C`.

Файл базы не удаляется при перезапуске. Не стирай `ball_bot.db`, `ball_bot.db-wal` и `ball_bot.db-shm`, пока бот нужен. `Unauthorized` значит, что токен недействителен.

После обновления бота участнику достаточно нажать `/start`: нижние кнопки обновятся.

## База на сервере

Локально это файл SQLite рядом с проектом. На сервере тот же файл должен лежать на диске, который не пропадает при перезапуске контейнера.

Docker Compose уже кладёт базу в папку `data/` и поднимает бота заново, если процесс упал:

```bash
docker compose up -d --build
```

В контейнере `DATABASE_URL` указывает на `./data/ball_bot.db`. Папку `data/` не удаляй: это и есть анкеты. Копия на всякий случай: `cp data/ball_bot.db data/ball_bot.db.bak`.

Без Docker подойдёт `deploy/ball-bot.service`: положи проект в `/opt/ball-bot`, в `.env` укажи `DATABASE_URL=sqlite+aiosqlite:///./data/ball_bot.db`, затем `systemctl enable --now ball-bot`.

Postgres тоже подходит: в `DATABASE_URL` можно поставить адрес базы, бот сам переведёт его на async-драйвер. Таблицы создаются при старте, существующие строки не стираются.

Когда будут хост, пользователь и способ входа на сервер, бота можно поднять отсюда из терминала.
