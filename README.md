# Бот для поиска пары на бал

Telegram-бот для студенческого бала: заполнил анкету, полистал чужие, лайкнул — если лайк взаимный, можно написать друг другу.

Не приложение для знакомств. Просто помочь найти партнёра на вечер.

---

## Как запустить

Нужны Python 3.11+ и токен бота.

**1. Создай бота** в [@BotFather](https://t.me/BotFather): `/newbot` → скопируй токен.

Свой Telegram id узнай у [@userinfobot](https://t.me/userinfobot) — для админ-команд.

**2. Поставь зависимости:**

```bash
python3 -m venv .venv
source .venv/bin/activate          # Windows: .venv\Scripts\activate
pip install -r requirements.txt
cp .env.example .env
```

**3. Заполни `.env`:**

```env
BOT_TOKEN=токен_от_BotFather
ADMIN_IDS=твой_telegram_id
DATABASE_URL=sqlite+aiosqlite:///./ball_bot.db
```

`ADMIN_IDS` можно через запятую, если админов несколько.

**4. Запусти:**

```bash
python -m bot.main
```

В консоли будет `Бот запущен`. Остановка — `Ctrl+C`.

База `ball_bot.db` создаётся сама при первом старте.

Если видишь `Unauthorized` — токен кривой или отозван. Возьми новый у BotFather и обнови `.env`.

## Что умеет бот

- **Анкета** — имя, пол, курс/факультет, рост (по желанию), опыт танцев, «о себе», фото. Парни видят девушек и наоборот.
- **Лента** — все подходящие анкеты сразу: можно листать ← →, смотреть всех, потом лайкать кого угодно (и не одного).
- **Кому я нравлюсь** — кто лайкнул тебя; можно ответить и получить match.
- **Match** — обоим приходит анкета и кнопка «Написать» (если есть @username).
- **Моя анкета** — посмотреть, поправить, скрыть, удалить или заполнить заново.

## Админка

У id из `ADMIN_IDS` в нижнем меню есть кнопка **Админка** (те же действия — и слэш-командами):

| Кнопка / команда | Зачем |
|------------------|--------|
| Админка / `/admin` | Панель команд |
| Статистика / `/stats` | Сколько анкет, лайков, match |
| Список анкет / `/users` | По 10 штук; можно нажать на имя |
| Открыть анкету / `/user id\|@nick` | Карточка: id, @username или список |
| Рассылка / `/broadcast` | Текст следом или сразу в команде |
| Бан / Разбан | id, @username или выбор из списка |

Без аргумента (`/user`, `/ban`…) — тот же пошаговый выбор, что и у кнопок.

## Где что лежит

```
bot/
  main.py        — запуск
  texts.py       — все тексты (название бала — BALL_NAME)
  handlers/      — сценарии
  db/            — модели (SQLite локально / Postgres на Railway)
  keyboards/     — кнопки
```

Тексты и название мероприятия правь в `bot/texts.py`.

## На заметку

- Один бал — один бот и одна база.
- Попроси ребят открыть @username в Telegram — иначе после match сложнее связаться.

## Railway: чтобы анкеты не слетали

На Railway файлы контейнера **стираются при каждом деплое**.  
Поэтому SQLite-файл `ball_bot.db` внутри сервиса — плохая идея: после коммита база пустая.

### Правильный вариант — PostgreSQL

1. В проекте Railway: **New** → **Database** → **PostgreSQL**.
2. В сервисе бота открой **Variables**.
3. Подключи переменную `DATABASE_URL` из Postgres  
   (Reference → Postgres → `DATABASE_URL`),  
   **или** удали свой ручной `DATABASE_URL` на sqlite, если он был.
4. Оставь `BOT_TOKEN` и `ADMIN_IDS` как были.
5. Задеплой заново.

Бот сам переведёт `postgresql://…` в async-драйвер. Таблицы создадутся при старте.

Локально по-прежнему можно использовать sqlite из `.env`.

> Уже пропавшие анкеты с прошлого деплоя **не вернуть** — их негде было сохранить. После Postgres новые анкеты останутся между деплоями.
