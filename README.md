# Бот для поиска пары на бал

Telegram-бот для студенческого бала: заполнил анкету, полистал чужие, лайкнул — если лайк взаимный, можно написать друг другу.

Не приложение для знакомств. Просто помочь найти партнёра на вечер.

---

## Как запустить

Нужны Python 3.11+ и токен бота.

**1. Создай бота** в [@BotFather](https://t.me/BotFather): `/newbot` → скопируй токен.

Свой Telegram id узнай у [@userinfobot](https://t.me/userinfobot) — для админ-команд.

**2. Поставь зависимости:**

```bash
python3 -m venv .venv
source .venv/bin/activate          # Windows: .venv\Scripts\activate
pip install -r requirements.txt
cp .env.example .env
```

**3. Заполни `.env`:**

```env
BOT_TOKEN=токен_от_BotFather
ADMIN_IDS=твой_telegram_id
DATABASE_URL=sqlite+aiosqlite:///./ball_bot.db
```

`ADMIN_IDS` можно через запятую, если админов несколько.

**4. Запусти:**

```bash
python -m bot.main
```

В консоли будет `Бот запущен`. Остановка — `Ctrl+C`.

База `ball_bot.db` создаётся сама при первом старте.

Если видишь `Unauthorized` — токен кривой или отозван. Возьми новый у BotFather и обнови `.env`.

## Что умеет бот

- **Анкета** — имя, пол, курс/факультет, рост (по желанию), опыт танцев, «о себе», фото. Парни видят девушек и наоборот.
- **Лента** — карточки по одной: ❤️ лайк, 👎 дальше, 💤 в меню.
- **Кому я нравлюсь** — кто лайкнул тебя; можно ответить и получить матч.
- **Матч** — обоим приходит анкета и кнопка «Написать» (если есть @username).
- **Моя анкета** — посмотреть, поправить, скрыть, удалить или заполнить заново.

## Админка

Команды работают только у id из `ADMIN_IDS`:

| Команда | Зачем |
|---------|--------|
| `/admin` | Список команд |
| `/stats` | Сколько анкет, лайков, матчей |
| `/users` | Все анкеты (по 10, с кнопками далее/назад) |
| `/user 123456` | Одна анкета с фото по telegram id |
| `/broadcast текст` | Рассылка всем с анкетой |
| `/ban 123456` | Забанить |
| `/unban 123456` | Разбанить |

`/broadcast` без текста — бот попросит текст следующим сообщением.

## Где что лежит

```
bot/
  main.py        — запуск
  texts.py       — все тексты (название бала — BALL_NAME)
  handlers/      — сценарии
  db/            — SQLite-модели
  keyboards/     — кнопки
```

Тексты и название мероприятия правь в `bot/texts.py`.

---

## На заметку

- Один бал — один бот и одна база. На следующий год можно поднять заново или снести `ball_bot.db`.
- Попроси ребят открыть @username в Telegram — иначе после матча сложнее связаться.
- На сервере удобно держать в `tmux` / `screen` / systemd, чтобы не падал при закрытии ноутбука.
